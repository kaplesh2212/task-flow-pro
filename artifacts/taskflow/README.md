# Infinity Focus 🧠

**Infinity Focus** is a premium, high-engagement productivity operating system designed to help you master your day. Built with a "Neural Command Center" aesthetic, it combines tasks, habits, and a cinematic focus timer into one cohesive experience.

## ✨ Features

- **Neural Hub (Dashboard)**: Real-time productivity tracking with "Prestige Streak" analytics.
- **Deep Work Tasks**: A high-fidelity mission control for your daily objectives.
- **Atomic Habits**: Gamified habit tracking with all-time best streaks and legendary badges.
- **Cinematic Timer**: A focus stopwatch with integrated soundscapes (Rain, Ocean, White Noise).
- **Neural Sync AI**: Behavioural analysis to optimize your focus patterns.
- **Glassmorphic UI**: Premium SaaS aesthetic with perfect Dark/Light mode parity.

## 🚀 Getting Started

### Prerequisites

- Node.js (v18 or higher)
- npm or yarn

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/YOUR_USERNAME/infinity-focus.git
   ```
2. Navigate to the project directory:
   ```bash
   cd infinity-focus
   ```
3. Install dependencies:
   ```bash
   npm install
   ```
4. Start the development server:
   ```bash
   npm run dev
   ```

## 🛠️ Tech Stack

- **Framework**: React + Vite
- **Styling**: Tailwind CSS
- **Animations**: Framer Motion
- **State Management**: TanStack Query (React Query)
- **Icons**: Lucide React
- **SFX**: Custom Audio Engine
